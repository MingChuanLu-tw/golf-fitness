# 高爾夫體能 16 週：網頁 App

iPad 和 iPhone 都能跟練的訓練網頁。課表、規則和影片全部來自 `docs/plan.md`；紀錄先存在裝置上，連上 Google Sheet 後自動同步。

## 目前完成的功能（v0.1）

- **今日**：第幾週、哪一期、今天的課表（A／B／C 依序輪替，也可以手動換）、本週進度、複測週／下場週／春節提示、器材與回診提醒、每日活動度打卡（週日記錄坐姿穿襪的下背分數）
- **訓練前檢查**：輸入血壓、睡眠、狀況；依計畫書第二節判斷正常、降一級或只做活動度（收縮壓 ≥140 會先倒數 5 分鐘請你重量）
- **跟練**：iPad 橫向左右版面、iPhone 直向上下版面；示範影片、熱身與收操倒數、成對輪流、組間休息倒數、輸入心率（>120 提醒休息到 100 以下）、每組記錄次數／重量／RPE／動作走樣／疼痛、爆發力暖身組、「不舒服」按鈕、語音提示、螢幕常亮、中途關掉可以接著做
- **規則**：第一期第 3–4 週自動 +2 下、第 4 週硬舉 3 × 12 測試、12kg 進入條件（在「更多」勾選後改用 12kg 並加入擺盪）、第三期跳躍依週次切換、出差模式、週末課快走、下場週減量
- **紀錄**：每次訓練與每一組的明細
- **測試**：第 0、4、8、12、16 週的篩檢與體能測試表，自動顯示第 0 週數值
- **動作庫**：所有動作的影片與呼吸提示
- **更多**：Google Sheet 連線、器材勾選、12kg 進入條件、回診問題與答案、語音、匯出全部資料
- **同步**：離線也能用；每筆資料有唯一 id，重複上傳不會重複；iPad 和 iPhone 互相看得到

還沒做（下一階段）：自動調整建議、16 週日曆、模擬器擊球數據上傳、下場成績、趨勢圖、教練週報圖卡。

## 部署步驟

### 1. 放到 GitHub Pages（約 10 分鐘）

1. 登入 GitHub，按右上角「＋」→「New repository」，名稱填 `golf-fitness`，選 **Public**，其他不用勾，按「Create repository」。
2. 把這個資料夾的檔案放上去：告訴 Claude repo 名稱，由 Claude 推上去；或在 repo 頁面按「uploading an existing file」，把資料夾裡的所有檔案拖進去，按「Commit changes」。
3. repo 頁面 →「Settings」→ 左側「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，按「Save」。
4. 等 1–2 分鐘，網址會是 `https://你的帳號.github.io/golf-fitness/`。

> repo 是公開的：程式碼任何人都看得到，但**紀錄不在 repo 裡**，只存在你的裝置和你自己的 Google Sheet。不要把 token 寫進任何檔案。

### 2. 加到 iPad 和 iPhone 主畫面

用 **Safari** 打開上面的網址 → 點「分享」→「加入主畫面」。之後從主畫面圖示打開，就是全螢幕的 App。
注意：刪掉主畫面圖示，裝置上還沒同步的資料也會一起消失；所以先完成第 3 步的同步設定。

### 3. 建立 Google Sheet 與 Apps Script（約 15 分鐘）

1. 在 Google 雲端硬碟新增一份 Google 試算表，命名為「高爾夫體能紀錄」。
2. 選單「擴充功能」→「Apps Script」。把編輯器裡的內容全部刪掉，貼上 `apps-script/Code.gs` 的全部內容，按儲存。
3. 左側「專案設定」（齒輪）→ 最下面「指令碼屬性」→「新增指令碼屬性」：
   - 屬性 `TOKEN_WEB`，值填一串只有你知道的長密碼（20 個字以上的英數字），網頁用。
   - 屬性 `TOKEN_SIM`，另一串密碼，之後給模擬器上傳程式用（可以先不填）。
4. 回到編輯器，上方函式選 `setupSheets`，按「執行」。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。執行完，試算表會出現 11 個分頁。
5. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網頁沒有登入功能，所以要選所有人；安全性靠 token 保護）
   - 按「部署」，複製「網頁應用程式網址」（以 `/exec` 結尾）。
6. 在 iPad 和 iPhone 的 App 裡，各自到「更多」→ 貼上網址和 `TOKEN_WEB` →「儲存並測試連線」，看到「連線成功」就完成了。

### 之後要更新時

- **改了 Apps Script**：「部署」→「管理部署作業」→ 編輯（鉛筆）原本那個部署 → 版本選「新版本」→「部署」。**不要按「新增部署作業」**，否則網址會改變，網頁就連不上。
- **改了課表**：先改 claude.ai 上的計畫書並匯出覆蓋 `docs/plan.md`，再改 `tools/build_program.py`，執行：
  ```
  python3 tools/build_program.py
  python3 tools/check_program.py   # 必須顯示「全部一致」
  ```
  然後把 `sw.js` 第一行的 `VERSION` 加 1（例如 `gf-v1` → `gf-v2`），推上 GitHub。裝置下次打開會出現「有新版本，點此更新」。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`styles.css` | 畫面 |
| `js/app.js` | 各頁面、跟練流程 |
| `js/engine.js` | 規則引擎：日期 → 課表、訓練前判斷、步驟展開 |
| `js/db.js` | 裝置上的資料庫（IndexedDB） |
| `js/sync.js` | 和 Google Sheet 同步 |
| `program.json` | 課表與規則資料（由 `tools/build_program.py` 產生，不要手改） |
| `sw.js`、`manifest.webmanifest`、`icons/` | 離線與加到主畫面 |
| `apps-script/Code.gs` | Google Sheet 後端 |
| `tools/` | 產生與檢查 program.json |
| `docs/` | 計畫書、規格書、開工說明 |
